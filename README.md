# Fortyn — mídias de exercícios

Lote de 1.142 GIFs preservados em suas pastas e nomes de origem para uso pelo aplicativo Fortyn.

Os arquivos são mantidos sem alteração de movimento. Itens estáticos permanecem estáticos e devem ser tratados pelo aplicativo como imagem/pose, não como demonstração animada.

O arquivo `data/exercise_catalog.json` contém os nomes em pt-BR, tags de equipamento, região corporal, padrão de movimento, ambiente e estado de revisão. Use `relativePath` ou `mediaUrl` para localizar cada GIF.
